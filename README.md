# Pewpew's Deco Tools
A Guild Wars 2 Nexus addon for working with large Homestead and Guild Hall decoration layout XML files.

## Features
- Move complete decoration layouts in-game
- Convert layouts between Homesteads and Guild Halls
- Check required and available decorations
- Merge multiple decoration layouts
- Extract individual groups from merged layouts
- Export converted layouts without overwriting previous versions

## Requirements
- Guild Wars 2
- Raidcore Nexus
- A valid Guild Wars 2 API key (progression, guilds, account, inventories, unlocks)

## Installation
1. Download the latest DecoTools release.
2. Place `DecoTools.dll` in the appropriate Nexus addon directory OR for public releases, launch the Nexus Library and install Pewpew's Deco Tools directly.
3. Start Guild Wars 2.
4. Open DecoTools from the Nexus addon menu or its menu-bar icon.

## Local Data
DecoTools stores its settings and local decoration database in its addon folder.
The user’s API key and generated settings files are not included in this repository.
